# Changelog

## [1.0.0] — 2026-11-16

### Added
- Вывод ошибок валидации сервера (`details`) в формах входа/регистрации, добавления товара и заявки.
- Понятное сообщение при `429` (слишком много попыток входа).
- Каталог, вход/регистрация по JWT, форма заявки, тесты, деплой на Vercel (из ЛР5–ЛР10).
